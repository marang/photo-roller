# v0.1.0

First qualified Linux release of PhotoRoller.

- Plan and import camera media into dated album and event folders.
- Interactive source, target, preflight, execution, and verification wizard.
- Collision handling and optional cleanup restricted to verified copies.
- Updated dependencies and patched Go 1.26.10 build baseline.
- Linux amd64 and arm64 archives with SHA-256 checksums.

Install `rclone` separately and preview an import with `photoroller plan` before
starting `photoroller run`. Source and target paths can be set explicitly with
`--source` and `--target`.
